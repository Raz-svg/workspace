# Java Starter Project

Starter Java 27 project configured with Gradle (Kotlin DSL) and JUnit 5.

## Prerequisites

- **JDK**: OpenJDK 27 (`JAVA_HOME=C:\Users\akshi\.jdks\openjdk-27`)
- **Build tool**: Gradle 9.9.1 (or the included Gradle Wrapper `.\gradlew.bat`)

## Common Commands

```powershell
# Run the application
.\gradlew.bat run

# Run tests
.\gradlew.bat test

# Build and verify everything
.\gradlew.bat check
```
